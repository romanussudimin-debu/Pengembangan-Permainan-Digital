# Checklist Pengumpulan

| Luaran wajib | Lokasi | Status |
|---|---|---|
| a) File executable (.exe / web build) | `build/` → buat lewat `docs/PANDUAN-MENJALANKAN-DAN-EKSPOR.md` bagian B/C | ☐ **perlu diekspor di laptop Anda** |
| b) Source code project | `src/` (project Godot) + `tools/` (generator aset) | ☑ |
| c) Dokumentasi desain (GDD + asset references) | `docs/gdd/GDD.md`, `docs/gdd/asset-references.md` | ☑ (isi [NAMA]/[NIM]) |
| d) Laporan penelitian budaya (3–5 halaman) | `docs/riset/laporan-penelitian-budaya.md` (±2.000 kata) | ☑ (isi [NAMA]/[NIM]; verifikasi entri [PERLU VERIFIKASI]) |
| e) Video demo gameplay (1–2 menit) | ikuti `docs/laporan/naskah-video-demo.md` | ☐ **perlu direkam** |
| Laporan proses development | `docs/laporan/laporan-proses-development.md` | ◐ isi bagian playtest & screenshot |
| Presentasi | `docs/laporan/presentasi.md` → buat slide | ☐ |

## Urutan kerja sebelum deadline
1. Buka project di Godot dan mainkan sampai ending (±30 menit, termasuk memperbaiki error bila ada).
2. Playtest dengan 3 orang dan isi `hasil-playtest.md` (±45 menit).
3. Ekspor .exe (±20 menit, termasuk mengunduh template).
4. Rekam & sunting video (±45 menit).
5. Isi [NAMA]/[NIM], screenshot, dan hasil playtest di laporan; ekspor dokumen ke PDF (buka .md di VS Code/Typora/Google Docs → PDF).
6. Buat slide dari `presentasi.md`.
