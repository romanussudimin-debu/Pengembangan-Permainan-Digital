# Glosarium Istilah Manggarai

Untuk `penulis-narasi` dan UI. Kode [S#] → daftar pustaka di `catatan-riset.md` (diakses 12 November 2026).
Kolom **Aman di dialog?**: ✔ = terverifikasi, boleh dipakai; ⚠ = boleh dengan hati-hati/konteks; ✘ = jangan dipakai sampai diverifikasi penutur asli.
Catatan ejaan: sumber berbeda dalam penulisan (mis. *tu'a/tua*, *pe'ang/peang*). Gunakan ejaan di kolom Istilah secara konsisten.

**Rekomendasi dialog:** pakai *ité* untuk menyapa tetua, *ema* untuk ayah/bapak, *neka rabo* untuk "maaf", *Mori Kraeng* untuk menyebut Tuhan dalam doa syukur, serta istilah benda/tempat (lingko, lodok, moso, compang, mbaru gendang, songke, larik, nggiling, panggal). Salam pembuka gunakan Bahasa Indonesia sampai *tabe/di'a* diverifikasi.
